# Розробка функціоналу Backend

1. Реалізуй запитаний функціонал, дотримуючись існуючої архітектури.
2. Виконай лише перевірки, що стосуються зміненого коду.
3. Коротко опиши, що було реалізовано.
4. Сформуй готовий промпт для Frontend Codex, який містить:
   - Що потрібно реалізувати на frontend.
   - API endpoints, формати запитів і відповідей.
   - Авторизацію та обробку помилок.
   - Socket.IO події та payloads, якщо використовуються.
   - Що перевірено, а що залишається неперевіреним.

Використовуй фактичний код як джерело інформації.
Не вигадуй API-контракти.
Не змінюй frontend.
Не створюй коміти та не виконуй push без дозволу.
