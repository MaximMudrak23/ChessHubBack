# Виправлення багів Backend

1. Досліди проблему та знайди її першопричину.
2. За можливості відтвори баг перед виправленням.
3. Виправ проблему мінімальними змінами, дотримуючись існуючої архітектури.
4. Перевір, чи не порушено пов'язаний функціонал.
5. Виконай лише релевантні перевірки. За потреби додай регресійний тест.

# Результат

1. Коротко поясни причину бага.
2. Опиши, що саме виправлено.
3. Вкажи, що перевірено, а що ні.
4. Якщо потрібні зміни на frontend — сформуй готовий промпт для Frontend Codex із точними API-контрактами та необхідними діями.
5. Якщо frontend не потребує змін — просто повідом про це.

Не вигадуй причин і результатів перевірок.
Не змінюй frontend.
Не виконуй сторонній рефакторинг.
Не створюй коміти та не виконуй push без дозволу.
